01 ComfyUI란?

노드 기반 AI 이미지 생성 도구

ComfyUI는 Stable Diffusion 모델을 시각적 노드 그래프로 제어하는 오픈소스 도구입니다. 텍스트 프롬프트만 입력하는 일반 AI 이미지 도구와 달리, 모델 로딩부터 샘플링, 후처리까지 전 과정을 노드로 분해하여 직접 설계할 수 있습니다.

VFX 현장에서 ComfyUI를 쓰는 이유

  • > 같은 캐릭터를 다양한 각도/조명으로 일관되게 생성
  • > 스타일은 유지하면서 배경/구도만 변경
  • > 한번 만든 워크플로우를 팀 전체가 재사용
  • > ControlNet, IP-Adapter 등으로 정밀한 제어 가능

03 노드별 역할 이해
Load Checkpoint
AI 모델 로딩
사전 학습된 AI 모델(.safetensors)을 GPU 메모리에 로드합니다. 모델에 따라 화풍, 퀄리티, 스타일이 달라집니다. 출력: MODEL, CLIP, VAE 세 가지를 동시에 제공합니다.
CLIP Text Encode
프롬프트 → 벡터 변환
사람이 쓴 텍스트 프롬프트를 AI가 이해할 수 있는 수치 벡터(conditioning)로 변환합니다. Positive(원하는 것)와 Negative(피할 것) 2개를 사용합니다.
Empty Latent Image
빈 캔버스 생성
지정한 해상도의 빈 잠재 공간(latent space)을 생성합니다. 이 빈 캔버스 위에 KSampler가 이미지를 그려넣습니다. 가로/세로 비율을 여기서 결정합니다.
KSampler
이미지 생성 엔진
실제 이미지를 생성하는 핵심 노드입니다. 노이즈 제거(denoising) 과정을 반복하며 이미지를 만듭니다. Steps, CFG, Sampler 등 품질을 결정하는 핵심 파라미터를 제어합니다.
VAE Decode
잠재 공간 → 이미지 변환
KSampler가 만든 잠재 공간(latent) 데이터를 사람이 볼 수 있는 픽셀 이미지로 디코딩합니다. VAE의 품질에 따라 세부 디테일이 달라집니다.
Save Image
결과물 저장
생성된 이미지를 파일로 저장합니다. 파일명 접두사를 지정할 수 있으며, 메타데이터(프롬프트, 설정값)가 이미지에 포함됩니다.
각 노드는 독립적인 기능 단위로, 순서와 연결을 바꾸면 완전히 다른 파이프라인을 구성할 수 있습니다.
04 VFX 제작 현장 활용 시나리오
SCENARIO 01

콘셉트 아트 옵션 제안

연출팀의 요청에 따라 하나의 장면을 여러 분위기로 빠르게 시각화합니다. 동일한 워크플로우에서 프롬프트와 시드값만 변경하여 3~5개의 비주얼 옵션을 30분 내에 생성할 수 있습니다.

Checkpoint 교체 Seed 변경 CFG 조절
SCENARIO 02

스타일 일관성 유지

ControlNet과 IP-Adapter 노드를 추가하면 레퍼런스 이미지의 스타일을 유지하면서 구도나 배경만 바꿀 수 있습니다. 시퀀스 전체의 비주얼 톤을 통일하는 데 필수적입니다.

ControlNet IP-Adapter Style Transfer
SCENARIO 03

프리비즈 파이프라인 자동화

스토리보드의 각 컷을 워크플로우 템플릿으로 만들어두면, 프롬프트만 교체하여 8~12컷의 프리비즈를 일관된 스타일로 빠르게 생성할 수 있습니다.

Batch Processing Workflow Template Prompt Queue

M83 MetaScene Creator와의 연결

M83의 자회사 디블라트(DiBlAT)가 KIST와 공동 개발 중인 AI 프리비즈 프로그램 'MetaScene Creator'는 AI 기반 시각 자료 생성을 제작 파이프라인에 통합하는 도구입니다. ComfyUI의 노드 기반 워크플로우 설계 경험은 이러한 AI 프리비즈 도구를 이해하고 활용하는 데 직접적인 기반이 됩니다.

Phase 1: 기본 워크플로우

Text-to-Image 기본 파이프라인 구축 완료. 6개 핵심 노드(Load Checkpoint, CLIP Encode, KSampler, Empty Latent, VAE Decode, Save Image)의 역할과 연결 구조 이해. Stable Diffusion v1.5 모델로 첫 이미지 생성 성공.
